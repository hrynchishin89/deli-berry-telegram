# Deli Berry — запуск Telegram “по максимуму”

Сборка уже готова так, чтобы при запуске сама настроила Telegram-бота: имя, описание, команды и кнопку меню `Заказать 🍓`.

## Что уже укомплектовано

- Telegram-бот на Bot API.
- Telegram Mini App / web-каталог.
- Каталог с категориями и 22 товарами-черновиками.
- Две точки: Дыбенко 7/1 и Ржавки, с20.
- Корзина и оформление заказа.
- Доставка / самовывоз.
- Уведомления в Telegram-группу менеджеров.
- Кнопки статусов заказа у менеджеров.
- Админка заказов.
- CSV-выгрузка.
- Промокоды.
- Юридический чекбокс и черновые тексты.
- Автонастройка Telegram при старте.
- Заготовка под MAX позже.

## Важно про токен

Токен нельзя хранить в архиве и пересылать дальше. Вы уже получили токен от BotFather — вставьте его только в секретные переменные хостинга, в поле `BOT_TOKEN`.

## Самый короткий запуск на Render

1. Откройте Render.
2. Создайте `New Web Service`.
3. Загрузите этот проект или подключите GitHub-репозиторий.
4. Build Command:

```bash
npm install
```

5. Start Command:

```bash
npm start
```

6. В Environment вставьте переменные из файла:

```text
0_ПЕРЕМЕННЫЕ_ДЛЯ_RENDER_СКОПИРОВАТЬ.txt
```

7. В `BOT_TOKEN` вставьте токен от BotFather.
8. В `WEBAPP_URL` и `PUBLIC_URL` вставьте HTTPS-ссылку Render после первого деплоя.
9. Нажмите Manual Deploy / Deploy latest commit.

## Что произойдёт само

После запуска сервер сделает:

- настроит имя бота `Deli Berry`;
- настроит описание;
- настроит короткое описание;
- настроит команды `/start`, `/order`, `/catalog`, `/status`, `/help`, `/myid`, `/groupid`;
- если `WEBAPP_URL` уже задан и начинается с `https://`, поставит кнопку меню `Заказать 🍓`;
- запустит приём команд от клиентов;
- начнёт принимать заказы из Mini App.

## Как получить группу заказов

1. Создайте группу Telegram `Deli Berry — Заказы`.
2. Добавьте туда бота.
3. Напишите в группе:

```text
/groupid
```

4. Бот ответит ID группы.
5. Вставьте этот ID в переменную `MANAGER_CHAT_ID`.
6. Сделайте тестовый заказ.

## Проверка

Откройте:

```text
https://ВАШ-АДРЕС.onrender.com/api/health
```

Должно быть:

```json
{ "ok": true }
```

Потом откройте бота в Telegram и нажмите `Start`.

## Админка

Адрес:

```text
https://ВАШ-АДРЕС.onrender.com/admin.html?pin=ВАШ_PIN
```

PIN задаёте вы сами в переменной `ADMIN_PIN`.

## Если кнопка Mini App не появилась

1. Проверьте, что `WEBAPP_URL` начинается с `https://`.
2. Откройте консоль Render.
3. Выполните:

```bash
npm run telegram:setup
```

Или просто перезапустите сервис — автонастройка включена.
