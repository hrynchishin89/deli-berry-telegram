# Deli Berry Telegram Ready

Это готовый пакет для запуска Telegram Mini App и заказного Telegram-бота Deli Berry.

## Быстрый смысл

Покупатель открывает бота → нажимает «Заказать 🍓» → выбирает точку → собирает корзину → оставляет контакты → заказ падает в Telegram-группу менеджеров.

## Что изменилось в этой версии

- Добавлена безопасная первичная настройка через `/setup.html`.
- Добавлена команда `/manager`, чтобы не искать и не вставлять `MANAGER_CHAT_ID` вручную.
- Добавлен `preflight` — проверка перед запуском.
- Добавлена автонастройка Telegram на старте сервера.
- Добавлена защита от ситуации, когда у бота был webhook: сервер сам делает `deleteWebhook`, чтобы polling работал.
- Добавлен файл `ВАЖНО_ТОКЕН.md`.

## Важное про токен

Не используйте токен, который уже был отправлен в чат. В BotFather перевыпустите новый и вставьте его в `BOT_TOKEN`.

## Главные файлы

- `ЗАПУСК_СЕЙЧАС.md` — короткая инструкция запуска.
- `.env.example` — пример переменных.
- `.env.launch.template` — копипаст для хостинга.
- `webapp/` — клиентское приложение.
- `src/` — сервер, бот и API.
- `data/catalog.json` — каталог товаров.
- `data/orders.json` — заказы.
- `docs/` — подробные инструкции.

## Запуск

```bash
npm install
npm run preflight
npm start
```

После деплоя откройте:

```text
https://ваш-адрес/setup.html
```

Введите `ADMIN_PIN` и нажмите «Настроить Telegram».
