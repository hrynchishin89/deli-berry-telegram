# Установить патч Deli Berry: логотип + премиальный дизайн + каталог

## Что внутри
- реальный логотип Deli Berry;
- новый тёмный шоколадно-премиальный дизайн;
- полный каталог из публичного меню Яндекс/Yango Deli;
- инструкция по редактированию каталога и фото.

## Как поставить
1. Распакуйте ZIP.
2. GitHub → репозиторий `deli-berry-telegram`.
3. `Add file` → `Upload files`.
4. Перетащите папки:

```text
data
webapp
docs
```

5. Перетащите файл:

```text
README_УСТАНОВИТЬ_БРЕНД_ПАТЧ.md
```

6. Нажмите `Commit changes`.
7. Render сам перезапустится. Дождитесь `Live`.
8. Проверьте `https://deli-berry-telegram.onrender.com/api/health`.
9. Откройте бота → `Заказать 🍓`.

## Где менять каталог
Инструкция лежит здесь:

```text
docs/КАК_ЗАПОЛНЯТЬ_КАТАЛОГ.md
```
