# Установка Deli Berry V2 PRO ULTIMATE

Заменять токен, Render Environment и backend не нужно.

## Самый простой путь

1. Распакуйте ZIP.
2. Откройте GitHub → репозиторий `deli-berry-telegram`.
3. Нажмите `Add file` → `Upload files`.
4. Перетащите папки из архива:
   - `webapp`
   - `data`
   - `docs`
5. Внизу нажмите `Commit changes`.
6. Откройте Render и дождитесь статуса `Live`.
7. Проверьте: `https://deli-berry-telegram.onrender.com/api/health`.
8. Откройте Telegram-бот → `Заказать 🍓`.

## Что должно заработать

- мобильный скролл;
- клики по категориям;
- отдельный раздел напитков;
- карточки товаров;
- модалка товара;
- корзина;
- оформление заказа;
- отправка заказа в Telegram-группу менеджеров.
