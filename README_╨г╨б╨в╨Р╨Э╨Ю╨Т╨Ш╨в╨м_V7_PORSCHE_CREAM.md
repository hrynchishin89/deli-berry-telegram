# Deli Berry V7 Porsche Cream + Product Objects

Этот патч исправляет две проблемы из скриншотов:

1. фон был слишком мрачным;
2. фото товаров выглядели как плоские вставки.

## Что меняется

- общий фон становится кремово-тауповым, в стиле премиального салона / boutique lounge;
- карточки становятся светлее и дороже;
- товар в карточке показывается как объект на сцене;
- cutout-фото теперь используются первыми;
- старые stage-изображения используются только как запасной вариант;
- убран сильный перекос/поворот, из-за которого фото выглядело как плоская наклонённая карточка;
- добавлены мягкие тени, подиум, свет, глубина;
- обновлены версии CSS/JS, чтобы Telegram подтянул новый стиль.

## Как установить

1. Открой GitHub репозиторий `deli-berry-telegram`.
2. Нажми `Add file` → `Upload files`.
3. Перетащи папки из архива в корень репозитория:
   - `webapp`
   - `docs`
   - `README_УСТАНОВИТЬ_V7_PORSCHE_CREAM.md`
4. Нажми `Commit changes`.
5. Дождись Render `Live`.
6. Открой Telegram Mini App заново.

## Важно

Патч не трогает `data/catalog.json`, цены и товары. Он меняет только интерфейс и логику показа фото.

Для настоящего 3D нужны `.glb`-модели. Сейчас используется лёгкий pseudo-3D/object-stage формат, который быстро работает в Telegram.
