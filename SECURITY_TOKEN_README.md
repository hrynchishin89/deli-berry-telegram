# Важно про Telegram-токен

Токен бота — это ключ управления ботом. Если токен был отправлен в чат, письмо, таблицу или другой незащищённый канал, его лучше считать раскрытым.

## Что сделать сейчас

1. Откройте Telegram.
2. Найдите @BotFather.
3. Отправьте команду `/mybots`.
4. Выберите бота Deli Berry.
5. Нажмите **API Token**.
6. Нажмите **Revoke current token** или отправьте `/revoke`.
7. Скопируйте новый токен.
8. Вставьте новый токен только в переменные хостинга: `BOT_TOKEN`.

## Почему токена нет в ZIP

Я специально не вшиваю токен в архив и код. ZIP часто пересылают, загружают в GitHub, Render, Railway и облака. Если токен лежит внутри архива, любой, у кого есть архив, может управлять ботом.

## Где токен должен храниться

Только здесь:

- Render/Railway → Environment Variables → `BOT_TOKEN`;
- локально на вашем компьютере → файл `.env`, который не загружается в GitHub;
- не в коде;
- не в публичных документах;
- не в ZIP для пересылки.
