# 3D-анимации товаров Deli Berry

Что добавлено:

- товарные карточки получили CSS 3D-сцену;
- товар плавно крутится на витрине;
- при наведении/движении мыши товар поворачивается в сторону курсора;
- в карточке товара есть увеличенный 3D-preview;
- добавлены блики, орбиты, тени, кольца и глубина;
- при добавлении товара работает fly-to-cart анимация.

Важно: это лёгкая 3D-иллюзия без тяжёлых GLB-моделей. Она быстро работает внутри Telegram Mini App.

Настоящие 3D-модели можно подключить позже, если будут файлы `.glb`/`.usdz` для клубники, боксов и напитков. Для этого лучше заказать 3D-модели у дизайнера или сделать фотограмметрию товаров.
