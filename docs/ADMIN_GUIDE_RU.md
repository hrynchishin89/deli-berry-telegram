# Админка Deli Berry

## Заказы

Откройте `/admin.html`. Введите `ADMIN_PIN`. Здесь доступны список заказов, статусы и CSV-выгрузка.

## Клиенты и бонусы

Откройте `/loyalty-admin.html`. Здесь отображаются ID клиентов, баланс, сумма покупок и число завершённых заказов.

## Каталог

Откройте `/catalog-admin.html`. Можно:

- менять цену и описание;
- выбирать Дыбенко или Зеленопарк;
- добавлять варианты объёма;
- скрывать товар;
- загружать фотографию.

Чтобы каталог и фото переживали новый deploy, настройте `GITHUB_OWNER`, `GITHUB_REPO`, `GITHUB_BRANCH`, `GITHUB_TOKEN` в Render.
