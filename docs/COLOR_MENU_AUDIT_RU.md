## Ограничение исходных меню
Для фрешей, смузи, лимонадов, бабл-ти и чая в исходниках есть отдельные визуальные объекты — они вырезаны точечно. Для большинства строк горячего кофе исходное меню содержит цены, но не отдельное фото каждого напитка. Поэтому каждой кофейной карточке создан отдельный файл, но используется ближайший представитель стакана из того же меню. Позже его можно заменить реальным фото без изменения каталога.

## Особые правила
- Молочный коктейль — одна карточка с объёмом и обязательным выбором вкуса.
- Мокко и горячий шоколад — обязательный выбор вида шоколада.
- Бамбл — выбор апельсин / гранат.
- Альтернативное молоко — выбор кокосовое / миндальное / безлактозное.
- Джусболлы — выбор вкуса.
- Фреш «Яблоко–мята–клубника» — только 300 и 400 мл.
- Сливки +100 ₽ — отдельная позиция в «Добавках».
