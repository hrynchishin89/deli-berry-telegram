# Финальный чек-лист приёмки

- [ ] `/api/health`: `database=postgres`, `persistentDatabase=true`.
- [ ] Строгая Telegram-проверка включена.
- [ ] Дыбенко не показывает кофе и листовой чай.
- [ ] Зеленопарк показывает кофе, фреши, смузи и другие напитки.
- [ ] Объёмы меняют цену и попадают в корзину.
- [ ] Заказ приходит менеджеру.
- [ ] `Подтвердить`, `Оплачен`, `Готовится`, `Заказ готов`, `Завершён`, `Отмена` работают.
- [ ] Ответ менеджера приходит клиенту.
- [ ] `/pay` и `/qr` работают.
- [ ] Создаётся ID клиента.
- [ ] После завершения начисляются 5%.
- [ ] При отмене бонусы возвращаются.
- [ ] Во втором заказе списывается не более 30%.
- [ ] Протестировано на iPhone, Android и Telegram Desktop/Web.
- [ ] Заполнены график, доставка, реквизиты и юридические тексты.
