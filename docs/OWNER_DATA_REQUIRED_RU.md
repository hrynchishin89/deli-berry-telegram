# Данные, которые владелец должен заполнить до рекламы

1. График, доставка, минимальный заказ и контакты для обеих точек.
2. Юридические реквизиты продавца: статус, наименование, ИНН, адрес и контакт для претензий.
3. Финальная проверка актуальности товаров, цен, состава, аллергенов и фотографий.

Технически приложение может работать без этих данных, но публичный коммерческий запуск без них не рекомендуется.
