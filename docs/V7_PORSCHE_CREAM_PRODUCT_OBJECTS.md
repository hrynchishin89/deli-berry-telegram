# V7 Porsche Cream Product Objects

## Новая логика фото

В карточке товар выбирается так:

1. `cutout` — если есть вырезанный объект;
2. `image` — если есть обычное фото;
3. `stageImage` — только если других вариантов нет.

Это сделано потому, что baked stage-изображения выглядели плоско и иногда перекошенно.

## Как добиться эффекта Drinkit-style

Для каждого товара лучше иметь:

```json
"image": "/assets/products/product.jpg",
"cutout": "/assets/products/cutouts/product-cutout.png"
```

`cutout` — это PNG/WebP с товаром без фона. Приложение само ставит его на кремовую сцену, добавляет тень и мягкое движение.

## Что присылать для следующих партий фото

- фото товара крупно;
- без текста поверх;
- товар не обрезан;
- желательно светлый фон;
- название файла содержит название и цену.

Я обрабатываю фото и выдаю готовый патч.
