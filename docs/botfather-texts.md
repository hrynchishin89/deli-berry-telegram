# Тексты для BotFather

## Name

Deli Berry

## About

Клубника в шоколаде, сладкие подарки и десерты на заказ.

## Description

Откройте каталог Deli Berry, выберите точку, соберите корзину и отправьте заказ менеджеру. Наличие, цена и время приготовления подтверждаются менеджером.

## Commands

start - Запустить меню
order - Открыть каталог и заказ
catalog - Каталог Deli Berry
status - Проверить статус заказа
help - Помощь
myid - Узнать свой chat_id
groupid - Узнать ID группы
