# Как редактировать каталог

Файл: `data/catalog.json`.

У каждого товара есть поля:

- `id` — латиницей, не менять после запуска;
- `name` — название;
- `category` — категория;
- `description` — короткое описание;
- `composition` — состав;
- `price` — число для расчёта;
- `priceText` — как показывать цену;
- `unit` — вес или количество;
- `points` — `dybenko`, `rzhavki` или оба;
- `emoji` — временная картинка;
- `badge` — плашка;
- `isHit` — показывать в хитах;
- `allergens` — аллергены;
- `shelfLife` — срок годности;
- `needsConfirmation` — true, пока владелец не подтвердил.

После изменения файла перезапустите сервер.
