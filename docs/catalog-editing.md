# Редактирование каталога

Рекомендуемый способ: `/catalog-admin.html`.

Админка позволяет менять название, цену, описание, точки, варианты объёма, фото и видимость. Для постоянного сохранения файлов настройте GitHub CMS переменные из `.env.example`.

Файлы данных:

- `data/catalog.json` — базовый каталог;
- `data/catalog_addons.json` — актуальные добавления и переопределения;
- `data/categories_addons.json` — дополнительные категории;
- `data/points.json` — точки.

Не меняйте `id` существующего товара после запуска: он используется в истории заказов и повторном заказе.
