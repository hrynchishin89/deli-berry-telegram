# Решение ошибок

## `/api/health` показывает `database=json`

Добавьте в Render правильный `DATABASE_URL` (Internal Database URL) и выполните Save and deploy.

## Mini App отвечает 401

В боевом режиме это означает устаревшую или неподтверждённую Telegram-сессию. Закройте Mini App и откройте заново из бота. Не выключайте `REQUIRE_TELEGRAM_AUTH` публично.

## Заказ не приходит менеджеру

Проверьте `MANAGER_CHAT_ID`, добавление бота в группу и логи Render.

## Бонусы не начислились

Начисление происходит только после статуса `Завершён`. Проверьте, что база — PostgreSQL и `BONUS_ENABLED=true`.

## Фото из каталог-админки пропало после deploy

Настройте GitHub CMS переменные. Локальная файловая система Render не является постоянным хранилищем.

## Нужно отменить обновление

Render → Events → предыдущий успешный deploy → Rollback.
