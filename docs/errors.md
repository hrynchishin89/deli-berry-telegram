# Что делать при ошибках

## Бот не отвечает

Проверьте:

1. `BOT_TOKEN` вставлен без пробелов.
2. Сервер запущен.
3. В логах нет ошибки `ETELEGRAM`.
4. У вас не запущена вторая копия бота с тем же токеном.

## Кнопка меню не появилась

1. Проверьте, что `WEBAPP_URL` начинается с `https://`.
2. Запустите `npm run telegram:setup`.
3. Закройте и заново откройте чат с ботом.

## Заказ не приходит в группу

1. Добавьте бота в группу.
2. В группе отправьте `/groupid`.
3. Скопируйте ID в `MANAGER_CHAT_ID`.
4. Перезапустите сервер.
5. Сделайте тестовый заказ.

## Mini App открывается, но заказ не отправляется

1. Откройте `/api/health` — должно быть `ok: true`.
2. Проверьте, что сервер не спит/не выключен.
3. Временно поставьте `REQUIRE_TELEGRAM_AUTH=false`.
4. Проверьте логи хостинга.

## Админка пишет, что PIN не настроен

Поменяйте `ADMIN_PIN` на хостинге. Нельзя оставлять `change-me`.
