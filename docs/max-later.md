# MAX — позже на той же базе

Это приложение сделано как обычный мобильный web app. Его можно использовать:

- как Telegram Mini App;
- как обычную ссылку;
- как основу для MAX mini app, когда у владельца будет доступ к платформе MAX.

Для MAX нужно будет отдельно проверить:

- юридический статус: ИП/ООО/самозанятый;
- профиль организации;
- создание чат-бота;
- модерацию;
- HTTPS URL;
- правила обработки персональных данных;
- правила оплаты.

Код каталога и заказа уже отделён от Telegram настолько, чтобы не делать приложение заново.
