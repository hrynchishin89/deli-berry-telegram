# Безопасность токена Telegram

Токен бота — это ключ управления ботом.

Что делать правильно:

1. Не вставлять токен в код, ZIP, GitHub, публичные чаты и документы.
2. Хранить токен только в секретных переменных хостинга: `BOT_TOKEN`.
3. Если токен где-то засветился, в BotFather можно перевыпустить его через раздел управления ботом.
4. После перевыпуска старый токен перестанет работать, новый нужно вставить в `BOT_TOKEN` на хостинге.

Для тестового запуска можно использовать текущий токен, но для публичного запуска безопаснее перевыпустить его и заменить в Render/Railway.
