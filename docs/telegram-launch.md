# Telegram запуск без лишних действий

## Что скрипт делает сам

Команда `npm run telegram:setup` автоматически настраивает в Telegram:

- имя бота `Deli Berry`;
- описание бота;
- короткое описание;
- список команд;
- кнопку меню `Заказать 🍓`, открывающую Mini App.

## Что нельзя сделать без владельца

Telegram не даёт создать нового бота без аккаунта владельца. Поэтому владелец должен один раз создать бота через `@BotFather` и сохранить токен.

## Команды бота

- `/start` — главное меню;
- `/order` — открыть заказ;
- `/catalog` — открыть каталог;
- `/status НОМЕР` — статус заказа;
- `/myid` — личный chat_id;
- `/groupid` — ID группы менеджеров;
- `/today` — заказы за сегодня, только в группе менеджеров;
- `/export` — CSV выгрузка, только в группе менеджеров;
- `/pay НОМЕР ССЫЛКА` — отправить клиенту ссылку на оплату, только в группе менеджеров.

## Main Mini App в BotFather

После деплоя можно дополнительно зайти в BotFather:

1. `/mybots`.
2. Выбрать бота.
3. Bot Settings.
4. Configure Mini App / Main Mini App.
5. Вставить `WEBAPP_URL`.
6. Название: `Deli Berry`.
7. Описание: `Каталог сладких подарков и заказ клубники в шоколаде`.

Это добавит более заметную кнопку запуска приложения в профиле бота.
