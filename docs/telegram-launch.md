# Telegram — запуск и команды

Автонастройка команд и кнопки выполняется при старте (`SETUP_TELEGRAM_ON_START=true`) либо через `/setup.html`.

Клиентские команды:

- `/start` — открыть Deli Berry;
- `/order`, `/catalog` — открыть каталог;
- `/status НОМЕР` — проверить заказ;
- `/profile`, `/bonus` — профиль, ID и бонусный баланс.

Менеджерские команды в группе:

- `/manager` — назначить текущую группу;
- `/groupid` — показать ID группы;
- `/today` — заказы за день;
- `/export` — CSV;
- `/reply НОМЕР ТЕКСТ` — ответ клиенту;
- `/pay НОМЕР ССЫЛКА` — кнопка оплаты;
- `/qr НОМЕР ССЫЛКА` — локально сгенерированный QR.

Статусы доступны кнопками под заказом.
