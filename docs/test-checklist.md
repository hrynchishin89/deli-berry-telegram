# Чек-лист тестирования

## Telegram

- [ ] Бот отвечает на `/start`.
- [ ] Кнопка `Открыть каталог 🍓` открывает Mini App.
- [ ] Кнопка меню Telegram `Заказать 🍓` открывает Mini App.
- [ ] `/groupid` в группе показывает ID группы.
- [ ] Заказ приходит в группу менеджеров.
- [ ] Кнопки статуса меняют статус заказа.
- [ ] Клиент получает уведомление о статусе, если заказ оформлен из Telegram.

## Каталог

- [ ] Дыбенко выбирается.
- [ ] Ржавки выбирается.
- [ ] Категории переключаются.
- [ ] Поиск работает.
- [ ] Товар открывается в карточке.
- [ ] Товар добавляется в корзину.
- [ ] Количество меняется.

## Оформление

- [ ] Самовывоз оформляется без адреса.
- [ ] Доставка требует адрес.
- [ ] Имя обязательно.
- [ ] Телефон обязателен.
- [ ] Дата и время обязательны.
- [ ] Юридический чекбокс обязателен.
- [ ] После отправки корзина очищается.

## Админка

- [ ] `/admin.html` открывается.
- [ ] PIN работает.
- [ ] Заказы видны.
- [ ] CSV скачивается.
- [ ] Статусы меняются из админки.
