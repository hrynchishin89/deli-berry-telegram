# Как заполнять каталог Deli Berry

## Где лежит каталог
Основной файл:

```text
data/catalog.json
```

Категории:

```text
data/categories.json
```

Фото товаров:

```text
webapp/assets/products
```

## Как поменять цену
1. GitHub → `data/catalog.json`.
2. Нажмите карандаш `Edit`.
3. `Ctrl + F` → найдите название товара.
4. Измените две строки:

```json
"price": 2599,
"priceText": "2 599 ₽"
```

5. Внизу нажмите `Commit changes`.
6. Подождите Render → `Live`.

## Как поменять описание
В товаре измените строку:

```json
"description": "Новый текст описания"
```

Кавычки и запятую сохраняйте.

## Как добавить фото товара
1. Подготовьте фото: JPG или PNG, без русских букв в названии.
2. Пример названия:

```text
klubnika-belaya-12.jpg
```

3. GitHub → `webapp/assets/products` → `Add file` → `Upload files`.
4. Загрузите фото → `Commit changes`.
5. GitHub → `data/catalog.json` → найдите товар.
6. В строку `image` вставьте путь:

```json
"image": "/assets/products/klubnika-belaya-12.jpg"
```

## Как добавить новый товар
Скопируйте готовый блок товара и вставьте перед закрывающей квадратной скобкой `]`.

Шаблон:

```json
{
  "id": "new-product-001",
  "name": "Название товара",
  "category": "strawberry_chocolate",
  "categoryName": "Клубника в шоколаде",
  "description": "Короткое описание",
  "composition": "Клубника, шоколад, декор",
  "allergens": "молоко, соя; возможны следы орехов",
  "shelfLife": "уточняется",
  "unit": "12 шт.",
  "price": 2500,
  "priceText": "2 500 ₽",
  "points": ["dybenko", "rzhavki"],
  "image": "/assets/products/placeholder.svg",
  "emoji": "🍓",
  "badge": "Новинка",
  "isHit": false,
  "needsApproval": true,
  "source": "owner"
}
```

## Как указать точки
Только Дыбенко:

```json
"points": ["dybenko"]
```

Только Ржавки:

```json
"points": ["rzhavki"]
```

Обе точки:

```json
"points": ["dybenko", "rzhavki"]
```

Скрыть товар:

```json
"points": []
```

## Как добавить категорию
1. Откройте `data/categories.json`.
2. Добавьте блок:

```json
{ "id": "new_category", "name": "Новая категория", "emoji": "✨" }
```

3. В товарах используйте такое же значение:

```json
"category": "new_category"
```

## Важно
После каждого изменения GitHub автоматически запускает Render. Ждите статус `Live`, потом обновляйте Telegram Mini App.
