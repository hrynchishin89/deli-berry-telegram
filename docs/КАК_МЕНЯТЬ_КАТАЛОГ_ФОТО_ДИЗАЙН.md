# Как менять каталог Deli Berry — простая инструкция

## 1. Где лежит каталог

Главный файл каталога:

```text
data/catalog.json
```

Категории:

```text
data/categories.json
```

Фото товаров кладём сюда:

```text
webapp/assets/products/
```

## 2. Как быстро поменять цену

1. Откройте GitHub.
2. Откройте репозиторий `deli-berry-telegram`.
3. Откройте файл `data/catalog.json`.
4. Нажмите карандаш `Edit`.
5. Нажмите `Ctrl + F` и найдите название товара.
6. Поменяйте две строки:

```json
"price": 2599,
"priceText": "2 599 ₽"
```

7. Внизу нажмите `Commit changes`.
8. Render сам перезапустится.

## 3. Как поменять описание

В том же товаре меняйте строку:

```json
"description": "Ваш новый текст"
```

Не удаляйте кавычки и запятую в конце строки.

## 4. Как скрыть товар

Самый простой способ — убрать точку из строки `points`.

Было:

```json
"points": ["dybenko"]
```

Скрыть товар:

```json
"points": []
```

Потом `Commit changes`.

## 5. Как добавить фото товара

1. Подготовьте фото JPG или PNG.
2. Назовите файл коротко латиницей, например:

```text
strawberry-birthday.jpg
```

3. В GitHub откройте папку:

```text
webapp/assets/products
```

4. Нажмите `Add file` → `Upload files`.
5. Загрузите фото.
6. Нажмите `Commit changes`.
7. Откройте `data/catalog.json`.
8. Найдите товар.
9. В строке `image` вставьте путь:

```json
"image": "/assets/products/strawberry-birthday.jpg"
```

10. Сохраните через `Commit changes`.

## 6. Как заменить логотип

Сейчас приложение использует файл:

```text
webapp/assets/logo.svg
```

Если есть ваш настоящий логотип:

1. Пришлите его сюда или загрузите в GitHub в эту же папку.
2. Лучше формат SVG или PNG с прозрачным фоном.
3. Если файл PNG, назовите его `logo.png`, а потом я подскажу, какую одну строку поменять в `index.html`.

## 7. Как добавить новый товар

Самый безопасный способ:

1. Скопируйте целиком один похожий товар от `{` до `}`.
2. Вставьте рядом.
3. Поменяйте:
   - `id`
   - `name`
   - `description`
   - `price`
   - `priceText`
   - `unit`
   - `points`
   - `image`

Пример точки:

```json
"points": ["dybenko"]
```

или для обеих точек:

```json
"points": ["dybenko", "rzhavki"]
```

## 8. Проверка после изменений

Откройте:

```text
https://deli-berry-telegram.onrender.com/api/health
```

Должно быть:

```json
"ok": true
```

Потом откройте бота и нажмите `Заказать 🍓`.
