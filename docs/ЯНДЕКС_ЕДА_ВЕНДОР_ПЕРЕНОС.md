# Как перенести товары из Яндекс Еда Вендор в каталог Telegram Mini App

## Самый быстрый способ
1. Откройте Яндекс Еда Вендор.
2. Перейдите в раздел `Меню`.
3. Выберите точку: Дыбенко или Ржавки.
4. По каждой категории откройте товары и сверяйте поля:
   - название;
   - описание;
   - вес / количество;
   - цена;
   - фото;
   - стоп-лист / доступность.
5. Эти данные переносите в `data/catalog.json`.

## Если есть экспорт меню
Если в вашем кабинете есть выгрузка XLSX/CSV, скачайте файл и отправьте его в чат. Я соберу из него точный `catalog.json` без ручного копирования.

## Если экспорта нет
Сделайте скриншоты категорий и карточек товаров. Лучше по 10-20 товаров за раз. Я перенесу их в каталог.

## Правило точек
Каждый товар должен иметь поле `points`:

```json
"points": ["dybenko", "rzhavki"]
```

## Фото
Фото из Вендора лучше использовать только если они ваши. Названия файлов делайте латиницей.
