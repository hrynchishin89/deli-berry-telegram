# Как добавлять реальные фото в V5

1. Загрузите фото в GitHub в папку:

`webapp/assets/products`

2. Название файла делайте латиницей без пробелов:

`klubnika-belaya-12.jpg`

3. В `data/catalog.json` у нужного товара укажите:

`"image": "/assets/products/klubnika-belaya-12.jpg"`

4. Нажмите `Commit changes`.

После Render Live фото появится в карточке товара. Если фото не загрузилось, приложение покажет 3D-placeholder.
