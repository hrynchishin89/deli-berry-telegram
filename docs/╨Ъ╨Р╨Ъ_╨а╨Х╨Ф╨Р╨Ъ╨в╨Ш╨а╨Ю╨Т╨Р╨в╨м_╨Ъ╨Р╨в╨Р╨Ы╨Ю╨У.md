# Как редактировать каталог

Главный файл: `data/catalog.json`.

## Цена

Найдите товар и поменяйте:

```json
"price": 2599,
"priceText": "2 599 ₽"
```

## Фото

1. Загрузите фото в `webapp/assets/products`.
2. В товаре укажите:

```json
"image": "/assets/products/my-photo.jpg"
```

## Точки

Только Дыбенко:

```json
"points": ["dybenko"]
```

Только Ржавки:

```json
"points": ["rzhavki"]
```

Обе точки:

```json
"points": ["dybenko", "rzhavki"]
```

## Хит

```json
"isHit": true
```
