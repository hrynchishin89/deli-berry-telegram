# Дели Берри · Telegram-каталог v5

Каталог по утверждённой таблице v5 от 28.09.2026: 9 карточек, 16 вариантов, 13 исходных фотографий. Этот каталог подключён в коде к существующему серверу Express и Telegram-боту репозитория. Фактическое размещение проверяется отдельно.

## Запуск

Запускайте из корня репозитория:

```sh
npm ci
npm start
```

Готовая сборка в `miniapp/release/web`, изображения в `miniapp/public/products`. Корень сайта обслуживает новый каталог; существующие административные страницы и данные сохранены. Отдельный процесс бота не нужен.

В Telegram работают кнопка меню и inline-кнопка существующего бота: заявка отправляется на `/api/catalog-v5/orders` с проверяемой сервером подписью `initData`. Обычный браузер позволяет собрать и скопировать заявку, но не отправить её без Telegram-сессии.

Корзина сохраняется на устройстве. Неотправленная заявка сохраняет свой номер при повторе. Подписанная Telegram-сессия в хранилище браузера не записывается. После подтверждённой передачи менеджеру корзина очищается. Заявка ещё не означает подтверждённый или оплаченный заказ.

## Коммерческие правила

- Источник: `Deli_Berry_MASTER_CATALOG_v5_2026-09-28(1).xlsx`, листы «Каталог», «Варианты», «Дополнения», «Правила». Ранняя история SKU не подменяет текущие цены.
- Свежая линия: изготовление после заказа, от 20 минут; точное время зависит от заказа. Это не срок доставки.
- Готовые сублимированные наборы и букеты можно забрать сразу; наличие конкретного оформления подтверждается при заказе.
- Заказ к дате и времени — по полной предоплате после согласования. Оплата в приложение не подключена.
- A07 и B09 — разные букеты на 19 ягод; A07 только свежий. Набора на 40 ягод нет.
- 25 ягод — только крафтовая коробка. Старое фото белой коробки не используется; карточка оформлена типографически до актуальной съёмки.
- Фото — примеры оформления. Для сублимированной линии указано, что снимки относятся к свежей линии. Видимые украшения в букете сами по себе не доказывают полный состав за базовую цену.
- Запрещённые A04/B05/B08/C01 и исторические C03/D01 не включены. E01 не включён из-за неподтверждённой полной комплектации. Файлы конвертированы из переданных PNG в WebP без потери пикселей, ретушь не добавлялась.
- Точные адреса и часы не придумывались: текущий каталог содержит названия двух точек.

## Обновление сборки

Из корня репозитория:

```sh
npm --prefix miniapp ci
npm run catalog:test
npm --prefix miniapp run typecheck
npm --prefix miniapp run build
```

Версии и lockfile зафиксированы. Для сборки требуется Node.js >=22.13; существующий сервер выполняет готовую сборку на Node.js >=20. При изменении интерфейса коммитьте и исходники, и `miniapp/release/web`. Фотографии не дублируются в сборке.

Порядок размещения, сохранности данных и отката: `docs/catalog-v5-launch.md` в корне репозитория. Официальный протокол: https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app.
