# Дели Берри — самостоятельный сайт-каталог (Old Money)

Это **новая версия сайта** «Дели Берри» без Telegram Mini App. Вся рабочая версия находится в `site-old-money/index.html`: HTML, CSS, каталог, скрипты и корзина — в одном файле. Старое приложение из репозитория не изменялось и не удалялось.

## Что есть
- 9 товарных семейств, 16 ценовых вариантов из подтверждённого каталога от 28–29.09.2026.
- Реальные фото из `catalog-site/products/` **этого же репозитория**. Для набора из 25 ягод без подтверждённого фото оставлен заполнитель.
- Категории «Наборы» и «Букеты», фильтры по свежей/сублимированной клубнике, поиск и сортировка.
- Карточки, выбор варианта, подтверждённые дополнения, корзина и форма пожеланий.
- Точки: Discovery (Москва, Дыбенко, 7/1) и Зеленопарк (Ржавки, 2-й микрорайон, стр. 20).
- Телефон для связи: +7 (995) 901-47-24.

**Заказы автоматически не принимаются.** Форма формирует текст заявки для копирования и связи с оператором. Оплата Т-Банка, подтверждение заказов и уведомления пока не подключены. Не выдавайте страницу за работающий интернет-магазин с онлайн-оплатой.

## Запуск в браузере
Откройте `site-old-money/index.html` локально: сборка, Node.js и npm не требуются.

## Как бесплатно опубликовать сайт из GitHub
GitHub хранит код. Для публичного коммерческого сайта используем **Cloudflare Pages Free**, а не GitHub Pages: [ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) не предусматривают хостинг интернет-магазина.

1. В Cloudflare откройте **Workers & Pages → Create application → Pages → Connect to Git**.
2. Разрешите Cloudflare доступ к репозиторию `hrynchishin89/deli-berry-telegram`.
3. Production branch: `main`. Framework preset: `None`.
4. Build command: пустое поле (если интерфейс требует — `exit 0`).
5. Build output directory: `site-old-money`.
6. Deploy. Получите адрес `*.pages.dev`. Платный тариф и домен не нужны (пока укладываемся в бесплатные лимиты).
7. Проверьте сайт с телефона, фотографии из GitHub и шрифты Google Fonts.

Cloudflare Pages: https://developers.cloudflare.com/pages/get-started/git-integration/

## Фотографии
Сейчас загружаются с `https://raw.githubusercontent.com/hrynchishin89/deli-berry-telegram/main/catalog-site/products/`. Если архивные фото изменятся или адрес GitHub станет недоступен, карточки потеряют иллюстрации. Для независимости от GitHub лучше скопировать подтверждённые исходники в `site-old-money/products/` и поменять `originalPhotoRoot` в HTML. Нельзя подменять фото набора из 25 ягод снимком другого товара.
