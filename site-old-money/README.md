# Дели Берри · редакционная витрина (версия 2)

Самостоятельный статический сайт-каталог: `index.html` + фотографии из `products/`.
Внешнее приложение Telegram не требуется. Разметка, стили, логика корзины и каталога находятся в одном HTML-файле.

## Что исправлено 10 ноября 2026

- Полностью переделаны обложка, визуальная сетка, цветовая система и дизайн каталога. Вместо шаблонного разделения на две одинаковые колонки — редакционная верстка с асимметричными фотографиями, крупной типографикой, двумя визуальными коллекциями «Наборы» и «Букеты» и выразительным разделом о выборе подарка.
- Сохранены все исходные 9 товарных семейств и 16 ценовых вариантов. Ничего не добавлено и цены не переопределены.
- Каталог не использует вымышленные «хиты», «бестселлеры», отзывы или скидки.
- Для набора из 25 ягод, к которому нет подтверждённого фото, оставлен честный заполнитель.
- Все 9 использующихся фотографий скопированы из `catalog-site/products/` этого же GitHub-репозитория в `site-old-money/products/` с сохранением оригинального Git blob SHA. Сайт больше не зависит от `raw.githubusercontent.com` для изображений.
- Мобильная версия получила прямую ссылку на каталог. Две визуальные коллекции переключают фильтры и приводят в каталог.
- На карточке сублимированной клубники уточняется, что фото иллюстрирует оформление, а фактический вид изделия следует уточнить у оператора.
- При оформлении корзины сайт **не отправляет заказ автоматически**: готовит текст заявки для копирования или отправки через функции телефона. Онлайн-эквайринг Т-Банка не включён, банковских ключей в коде нет.

## Проверка

Проверено в Chromium на ширинах 360, 390, 430, 768, 1024 и 1440 px: 30 / 30 сценариев без ошибок JS и горизонтальной прокрутки. Проверены переходы между двумя коллекциями, фильтры, варианты товара, оформление A06, доплаты, корзина, форма заявки и стоимость. Снимки сделаны в локальной тестовой среде с искусственно отключённой сетью; при опубликовании требуется дополнительная проверка реальных изображений.

## Публикация

Сначала хранить код в GitHub. Бесплатный статический коммерческий сайт публиковать через **Cloudflare Pages Free** с корневой папкой `site-old-money` и без build-команды. GitHub Pages для действующего интернет-магазина не использовать.

GitHub → Cloudflare Pages → Connect to Git → repository `hrynchishin89/deli-berry-telegram` → production branch `main` → build output directory `site-old-money`.

Для передачи заказов и онлайн-оплаты потребуется защищённый backend (например, Cloudflare Worker + D1), проверка webhook Т-Банка и юридические тексты. Этого на статической странице пока нет.
