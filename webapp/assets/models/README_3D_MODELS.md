# 3D-модели товаров

Сейчас V5 использует лёгкую CSS/JS 3D-анимацию: товар вращается, плавает и реагирует на курсор/палец без тяжёлых файлов.

Для настоящих моделей позже сюда можно положить `.glb` файлы:
- strawberry.glb
- gift-box.glb
- drink-cup.glb
- dubai-chocolate.glb

Пока не загружайте тяжёлые 3D-файлы без оптимизации: Telegram Mini App должен быстро открываться на телефоне.
