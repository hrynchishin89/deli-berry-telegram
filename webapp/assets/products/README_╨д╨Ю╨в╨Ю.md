# Фото товаров

Сюда загружаются реальные фото товаров.

Рекомендации:
- формат: jpg/webp/png;
- размер: 1000–1600 px по ширине достаточно;
- название латиницей без пробелов: `klubnika-belaya-12.jpg`;
- путь в каталоге: `/assets/products/klubnika-belaya-12.jpg`.

Если фото пока нет, приложение использует брендовый 3D-placeholder.
