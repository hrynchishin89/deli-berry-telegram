# Deli Berry — боевая комплектация Telegram

Проект уже собран так, чтобы при запуске автоматически поднялись:

- Telegram-бот;
- Mini App-каталог;
- корзина;
- оформление заказа;
- уведомления менеджерам;
- статусы заказа;
- админка;
- выгрузка CSV;
- промокоды;
- юридические страницы;
- заготовка под MAX.

## Самый короткий запуск через Render

### 1. Загрузите проект

1. Откройте Render.
2. Создайте **New Web Service**.
3. Загрузите этот проект через GitHub или импортируйте репозиторий.
4. Build command:

```bash
npm install
```

5. Start command:

```bash
npm start
```

### 2. Вставьте переменные

Откройте файл `RENDER_ENV_COPY_PASTE.txt` и скопируйте значения в Environment Variables.

Минимально нужны:

```env
BOT_TOKEN=новый токен от BotFather
WEBAPP_URL=https://адрес-на-render.onrender.com
PUBLIC_URL=https://адрес-на-render.onrender.com
ADMIN_PIN=любой-пин-для-админки
REQUIRE_TELEGRAM_AUTH=false
NODE_ENV=production
```

`MANAGER_CHAT_ID` можно оставить пустым на первый запуск. Потом добавьте бота в группу заказов, напишите `/manager` — бот сам назначит эту группу для заказов.

### 3. Что настроится само

После запуска сервер сам вызовет Telegram API и поставит:

- имя бота Deli Berry;
- описание;
- короткое описание;
- команды `/start`, `/order`, `/catalog`, `/status`, `/myid`, `/groupid`, `/help`;
- кнопку меню **Заказать 🍓**, если `WEBAPP_URL` начинается с `https://`.

Отдельно можно выполнить:

```bash
npm run telegram:setup
```

### 4. Проверка

Откройте:

```text
https://ваш-адрес/api/health
```

Должно быть:

```json
{"ok":true}
```

Потом откройте Telegram-бота и нажмите `/start`.

### 5. Группа заказов

1. Создайте группу **Deli Berry — Заказы**.
2. Добавьте бота в группу.
3. Напишите в группе:

```text
/groupid
```

4. Скопируйте ID.
5. Вставьте в переменную `MANAGER_CHAT_ID`.
6. Сделайте тестовый заказ.

После этого каждый новый заказ будет падать в группу с кнопками статусов.

## Локальная проверка на компьютере

```bash
npm install
npm run wizard
npm start
```

Wizard создаст локальный `.env`. Этот файл не попадает в ZIP и GitHub.

## Проверка безопасности

```bash
npm run secret:scan
```

Если всё нормально, будет:

```text
OK: в коде и документах проекта не найден открытый Telegram-токен.
```
