# Важно про токен Telegram

Токен уже вставлен в приватный файл `.env`, чтобы вам было меньше действий.

Не публикуйте `.env` в открытом GitHub и не пересылайте архив посторонним.

После первого успешного запуска лучше перевыпустить токен в @BotFather и заменить `BOT_TOKEN` на хостинге, потому что токен был отправлен в чат.
