# Deli Berry — запуск после получения токена

Проект укомплектован под Telegram-бота Deli Berry. Токен в архив не записан специально: это ключ управления ботом.

## Что произойдёт при запуске

Когда на хостинге будут заполнены `BOT_TOKEN`, `WEBAPP_URL` и `PUBLIC_URL`, приложение при старте само настроит Telegram:

- имя бота: Deli Berry;
- описание;
- короткое описание;
- команды `/start`, `/order`, `/catalog`, `/status`, `/help`, `/myid`, `/groupid`;
- кнопку меню «Заказать 🍓» с открытием Mini App;
- отключит старый webhook, чтобы бот работал через встроенный polling.

## Самый короткий запуск

1. Откройте Render или Railway.
2. Создайте новый Node.js/Web Service.
3. Загрузите этот проект.
4. Команда установки: `npm install`.
5. Команда запуска: `npm start`.
6. Вставьте переменные из файла `render.env.copy-paste.txt`.
7. Нажмите Deploy.
8. После запуска откройте `https://ваш-адрес/api/health`. Должно быть `ok: true`.
9. Откройте бота в Telegram и нажмите `/start`.

## Группа заказов

1. Создайте группу «Deli Berry — Заказы».
2. Добавьте туда бота.
3. Напишите в группе `/manager`.
4. ID вставлять не нужно: команда `/manager` сохранит группу автоматически.
5. Сделайте тестовый заказ.

## Проверка заказа

1. В боте нажмите `/start`.
2. Откройте каталог.
3. Добавьте товар в корзину.
4. Оформите тестовый заказ.
5. Заказ должен прийти в группу менеджеров с кнопками статуса.

## Команды для проверки на хостинге

```bash
npm run preflight
npm run telegram:setup
```

Если `npm run telegram:setup` ругается на `WEBAPP_URL`, значит ещё нет публичной HTTPS-ссылки приложения.
