# 00 — старт Deli Berry Telegram Ready

Эта сборка уже укомплектована под вашего Telegram-бота. Токен лежит в приватном файле `.env`; в этой инструкции он не печатается.

## Что уже настроено

- Telegram-бот запускается вместе с сервером.
- Бот сам ставит имя, описание, команды и кнопку меню, когда появится HTTPS-ссылка.
- Mini App с каталогом, корзиной, двумя точками, доставкой/самовывозом и заказом.
- Уведомления менеджерам в Telegram-группу.
- Команда `/manager`, чтобы назначить группу заказов без ручного MANAGER_CHAT_ID.
- Страница `/setup.html`, чтобы привязать кнопку Telegram к адресу хостинга одной кнопкой.
- Админка `/admin.html`.

## Самый короткий запуск

1. Загрузите проект на Node.js-хостинг с HTTPS.
2. Команда установки: `npm install`.
3. Команда запуска: `npm start`.
4. После запуска откройте: `https://ВАШ-АДРЕС/setup.html`.
5. Введите PIN из файла `data/admin_pin.txt`.
6. Нажмите **Настроить Telegram**.
7. Создайте группу Telegram **Deli Berry — Заказы**.
8. Добавьте туда бота.
9. Напишите в группе `/manager`.
10. Откройте бота, нажмите `/start`, сделайте тестовый заказ.

## Как проверить

Откройте:

```text
https://ВАШ-АДРЕС/api/health
```

Должно быть `ok: true`.

Потом откройте:

```text
https://ВАШ-АДРЕС/setup.html
```

Статус должен показать, что токен есть, кнопка Mini App настроена, группа заказов назначена после `/manager`.

## Важно по безопасности

Не загружайте `.env` в открытый GitHub и не пересылайте архив посторонним. Токен был вставлен по вашей просьбе, поэтому после первого успешного теста безопаснее перевыпустить токен в @BotFather и заменить `BOT_TOKEN` на хостинге.
